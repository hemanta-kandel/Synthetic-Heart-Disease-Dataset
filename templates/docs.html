Documentation

To use this project you have to clone this project located at https://github.com/hemanta-kandel/Synthetic-Heart-Disease-Dataset.

How to clone the project

Requirements

  • Python
    • Flask
    • Numpy
    • Pandas
    • Scikit-learn & XGBoost
  • Other
    • Git
    • Browser(To run this app)

How to clone this project

To clone this project run 


    git clone https://github.com/hemanta-kandel/Synthetic-Heart-Disease-Dataset

To run this project


    flask -app app run
